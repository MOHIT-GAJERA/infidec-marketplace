## App name

The name under the launcher icon is set per platform. Change every place in this table:

| Where | File | Key |
|---|---|---|
| Android launcher label | `android/app/src/main/AndroidManifest.xml` | `android:label="ClassiAds Hub"` |
| iOS home-screen name | `ios/Runner/Info.plist` | `CFBundleDisplayName` (and `CFBundleName`) |
| Task switcher title | `lib/main.dart` | `MaterialApp.router(title: 'ClassiAds Hub')` |
| App constant | `lib/core/config/app_config.dart` | `AppConfig.appName` |
| Settings → About row | `lib/features/settings/settings_screen.dart` | `Text('ClassiAds Hub')` and `Text('Version 1.0.0')` |
| Rate dialog | `lib/features/profile/profile_screen.dart` | `'Rate ClassiAds Hub'` |
| Location permission text (iOS) | `ios/Runner/Info.plist` | `NSLocationWhenInUseUsageDescription`, `NSLocationAlwaysAndWhenInUseUsageDescription` |
| Notification channel name (Android settings) | `lib/core/services/notification_service.dart` | `'ClassiAds notifications'` |

```xml title="mobile/android/app/src/main/AndroidManifest.xml"
<application
    android:label="Your Classifieds"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher">
```

```xml title="mobile/ios/Runner/Info.plist"
<key>CFBundleDisplayName</key>
<string>Your Classifieds</string>
```

:::warning Replace the hard-coded website links too
Two actions copy a link to the demo website. Point them at your own domain:

- **Share** on the ad detail screen: `lib/features/ads/screens/ad_detail_screen.dart` copies `https://classiadshub.web.app/ad/<slug>`.
- **Share this App** on the profile screen: `lib/features/profile/profile_screen.dart` copies `https://classiadshub.web.app`.

Search the project for `classiadshub.web.app` and replace it with `https://www.yourcompany.com`.
:::

## Launcher icon

The icon is generated by `flutter_launcher_icons` from **`assets/app-icon.png`**. The config is in `pubspec.yaml`:

```yaml title="mobile/pubspec.yaml"
flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/app-icon.png"
  min_sdk_android: 21
  adaptive_icon_background: "#272757"
  adaptive_icon_foreground: "assets/app-icon.png"
  web:
    generate: true
    image_path: "assets/app-icon.png"
    background_color: "#272757"
    theme_color: "#272757"
```

:::steps
### Replace the image
Put your logo in `mobile/assets/app-icon.png`: a square PNG, at least **1024 × 1024**. For the Android adaptive icon keep the logo inside the centre ~66% of the canvas, because launchers crop the edges into circles or squircles.

### Set the adaptive background
Change `adaptive_icon_background` (and the web colours) to your brand colour. The value also ends up in `android/app/src/main/res/values/colors.xml` as `ic_launcher_background`.

### Generate
```bash
cd mobile
dart run flutter_launcher_icons
```
This rewrites the `mipmap-*` folders on Android, `AppIcon.appiconset` on iOS and the web icons.
:::

The same `assets/app-icon.png` is shown on the in-app splash screen (see below), so one file updates both.

## Native splash screen

The first screen the OS draws while Flutter starts is generated by `flutter_native_splash` from **`assets/512.png`** on a white background:

```yaml title="mobile/pubspec.yaml"
flutter_native_splash:
  color: "#FFFFFF"
  image: "assets/512.png"
  android_12:
    image: "assets/512.png"
    color: "#FFFFFF"
  android: true
  ios: true
  web: false
```

1. Replace `assets/512.png` with your logo (PNG, transparent background, about 512 × 512).
2. Change `color` if you want another background.
3. Generate:

```bash
cd mobile
dart run flutter_native_splash:create
```

On Android 12+ the system shows the image inside a circle mask, so keep the logo small and centred.

## In-app splash

After the native splash, the router shows `/splash` while it restores the Firebase session. The screen is `lib/features/auth/screens/splash_screen.dart`: the icon `assets/app-icon.png` at 200 × 200 on white, with no text and no spinner. Change the size or background there if needed.

## Onboarding slides

First-time users see three slides (`lib/features/auth/screens/onboarding_screen.dart`):

| Slide | Image | Title | Text |
|---|---|---|---|
| 1 | `assets/slide1.png` | Snap & List | Take a clean photo of what you want to sell — your ad goes live in under a minute. |
| 2 | `assets/slide2.png` | Discover Nearby | Browse thousands of fresh local listings and filter by distance, price, and category. |
| 3 | `assets/slide3.png` | Chat & Close Deals | Negotiate with buyers, accept offers, and complete trades — safely, all in one place. |

Replace the PNG files (keep the names, or update the `_slides` list) and edit the texts in the `_slides` list.

## Empty-state image

`assets/emty-data.png` is the illustration on the "No Data Found" screens (My Ads, Chats). Replace it with your own artwork under the same file name.

After any asset change, run `flutter clean` once if the old image still shows.
