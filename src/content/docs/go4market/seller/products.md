## Add and edit products

**Catalogue → Products → Add product** in the Seller panel (or **Products → Add product** in the Partner app). The editor is the same as the admin's ([Products, Variants & Stock](doc:admin/products)), limited to the seller's own store:

- name, module, category (tree picker), brand, unit, tags;
- price, MRP, stock, low-stock threshold, SKU and **barcode**;
- **variants** and the variant generator;
- for Food: **Veg / Non-veg** and **add-ons**;
- custom fields and images;
- **Generate with AI** for the descriptions.

![Seller products in the Partner app](/docs/go4market/images/app-partner-seller-products.webp "Products with status filters (All, Active, Pending, Rejected), search and barcode scan")

New products are **pending** until an admin approves them, unless the admin enabled **Auto-approve products** for the store. Rejected products show the reason.

## Stock

**Catalogue → Stock** (or **More → Stock** in the app) lists products by stock level. Update stock and variant stock at any time; stock-only changes never send a product back for approval. You get a notification when an item reaches its low-stock threshold or runs out.

## Bulk upload

**Catalogue → Bulk upload** works like the admin version, for the seller's own products. See [bulk upload](doc:admin/products#bulk-upload-and-bulk-update).

## Seller attributes

**Catalogue → Attributes**: sellers can create private attributes (for example a *Fit* list for clothing) in addition to the global ones. If an admin changes a global attribute you use, a **migration alert** banner explains what changed.

## Reviews

**Catalogue → Reviews** (`/catalog/reviews`, or **More → Reviews** in the app) lists reviews of your products with rating, comment and photos. Only customers with a delivered order can review.
