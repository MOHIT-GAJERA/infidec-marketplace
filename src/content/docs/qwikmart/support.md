## Before you contact us

1. Search these docs (<kbd>Ctrl</kbd> + <kbd>K</kbd>) and read the [FAQs](doc:faqs).
2. Check the troubleshooting tables in [Run the App](doc:app-customer/run-the-app#troubleshooting) and [Delivery App → Run the App](doc:app-delivery/run-the-app#troubleshooting).
3. Look at the **Functions logs** in the Firebase console — most errors are explained there.

## What to include

- Your **order ID / purchase e-mail**
- Which part: backend, Admin Panel, website, Customer App or Delivery App — and the version
- What you did, what you expected and what happened
- Screenshots and the exact error text (Functions log, browser console or `flutter run` output)

:::warning Never send secrets
Do not send passwords, service-account keys, payment secrets or keystores. If we need access we will ask for a temporary account.
:::

## What support covers

| Included | Not included |
|---|---|
| Help installing and configuring the product as documented | Custom features or design changes |
| Fixing bugs in the original code | Problems caused by modified code |
| Answering questions about how features work | Third-party service issues (Google, gateways, SMS providers) |
| Updates and bug-fix releases | Server administration, App Store / Play Store account issues |

## Installation service

Prefer us to do everything? Our team can create the Firebase project, deploy the backend, host the panel and website on your domain, re-brand and build the apps and publish them on Google Play — see [Installation](/installation).
